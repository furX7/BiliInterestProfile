# v0.1 来源组合与兴趣证据边界 Spec

状态：**待书面 Spec 审批**。2026-09-28 的来源组合聊天设计已获用户批准；本文件本身尚未获批准。

## 1. 背景与权威来源

本 Spec 将 v0.1 的来源组合冻结为可审查的产品范围，服务于“本地优先、只处理正常访问时可见的公开信息、输出可解释兴趣画像”的长期目标。

权威要求来自：

- Notion《B站兴趣画像｜项目 Idea》：公开数据可作为兴趣证据，但不同来源权重不同，结论应有证据且不得制造虚假的精确感。
- Notion《详细制作流程｜稳定性与扩展性优先》：v0.1 选择 2–3 个稳定公开来源；至少两个来源能稳定获取并标准化是进入 Phase 1 的必要条件。
- Notion《工程流程优化｜从 Issue 到 Release》：架构级工作必须经过书面 Spec 与用户审批，才可进入计划阶段。
- 已接受的 ADR-007：Source Qualification 与 Phase 0 Global Risk Gate 分开判断；来源 PASS 不代表 Phase 0 或后续工程已获准。

本 Spec 只描述来源组合和证据边界；不覆盖采集实现、Contract、评分、权限、存储、UI 或测试方案。

## 2. 当前事实与问题

截至 2026-09-28，本地 Phase 0 记录为 Source Qualification **PASS 2 / FAIL 1 / NOT_VALIDATED 1**：公开基础资料与公开动态在已证明的限定范围内 PASS；公开投稿因内容归属不足为 FAIL；公开收藏保持 NOT_VALIDATED。

基础资料的资格证据只证明身份/上下文信息可稳定读取，不能把它包装为第二类兴趣行为证据。公开动态是当前唯一已验证可承载兴趣相关正文的来源。若现在把投稿或收藏纳入，会超出已有证据并误称为可用来源。

## 3. 决定：v0.1 来源组合

### 3.1 公开动态：唯一兴趣行为证据源

v0.1 的兴趣推断只可使用当前已验证范围内、正常公开动态页面上可见的动态内容。该范围以现有 Phase 0 证据为准：正常已登录公开动态页、当前渲染卡片、已知正文结构，以及对引用、通用文案、合作占位和不可确认内容的拒绝或降级。

动态内容可形成兴趣相关的行为证据，但只能在其可追溯、归属可信且内容可确认时使用。缺少必要字段、归属不明、结构未知或页面状态不可信时，结果必须为 partial、unknown 或拒绝；不得补造内容、时间、链接或兴趣结论。

### 3.2 公开基础资料：身份与上下文，不参与兴趣推断

公开基础资料只用于确认分析对象和提供必要上下文，例如路由、UID、可见头部身份及公开自述的上下文信息。它不产生兴趣信号、不增加兴趣分数、不提高兴趣置信度，也不构成多源佐证。

### 3.3 明确排除的来源

| 来源 | v0.1 状态 | 原因 |
| --- | --- | --- |
| 公开投稿/作品 | 排除 | 当前为 FAIL；逐卡上传者与合作角色归属尚未充分确认。 |
| 公开收藏 | 排除 | 当前为 NOT_VALIDATED；重复稳定性与必要字段标准化证据不足。 |

排除并不代表这些来源永久不可用。未来若要纳入，必须作为新的范围变更：先完成相应的 Source Qualification 与所需用户批准，再修改本 Spec。

## 4. 产品表述与局限

v0.1 必须明确：兴趣结论当前来自**单一行为来源（公开动态）**，只能反映该来源在可见、可确认样本中的信号。

因此 v0.1 不得：

- 宣称“多源印证”“跨来源一致性”或等效结论；
- 用基础资料把单一行为来源包装成多源兴趣证据；
- 将投稿或收藏的未验证、失败或不可确认内容计入兴趣；
- 将 unknown、页面空壳、工具异常或访问限制当作空数据或正常数据。

该局限应作为产品结果和后续设计的约束，而非被评分规则静默掩盖。

## 5. 与 Phase 0 Gate 的关系

本决定仅冻结“2–3 stable public Sources”条目中的 v0.1 组合、用途与兴趣证据价值。它不更改其他 Gate 判定。

Phase 0 Global Risk Gate 仍为 **BLOCKED**。至少 pagination、logged-out 和同文档 SPA UID switch 仍分别为 NOT_VALIDATED 或 PARTIAL；它们需要在各自获得批准的范围内处理。本 Spec 不授权新 Spike，也不把未完成项目降级、删除或解释为通过。

即使本 Spec 获批准，仍须先完成 Global Gate 并取得用户对进入 Phase 1 的明确授权，才可初始化工程骨架或实施任何产品能力。

## 6. 非目标

本 Spec 不：

- 启动或设计新的浏览器 Spike；
- 修改 Notion、ADR-007 或现有 Gate 状态；
- 定义正式 SourceAdapter、EvidenceItem、兴趣评分、权限或网络请求；
- 引入服务器、账号、API Key、私有接口、凭据读取或任何绕过限制的方式；
- 授权进入 Phase 1、编写实施计划或实现代码。

## 7. 本 Spec 的验收条件

本 Spec 获用户书面批准时，确认以下陈述全部成立：

1. 公开动态是 v0.1 唯一兴趣行为证据源，且仅限已验证范围。
2. 公开基础资料仅用于身份与上下文，不参与兴趣推断或置信度提升。
3. 投稿和收藏均不进入 v0.1：前者保持当前 FAIL，后者保持 NOT_VALIDATED。
4. v0.1 对外和对内均不得宣称多源兴趣印证。
5. 本 Spec 不改变 Phase 0 Global Gate，也不授权 Phase 1、计划或实施。
