# v0.1 来源组合与兴趣证据边界 Spec

状态：**书面 Spec 已获用户批准**。来源组合及延期验证修订均已获批准；Phase 0 closure audit 和进入 Phase 1 的最终授权亦已取得。pagination 与 SPA UID switch 的子项证据状态及重验条件继续有效。

## 1. 背景与权威来源

本 Spec 将 v0.1 的来源组合冻结为可审查的产品范围，服务于“本地优先、只处理正常访问时可见的公开信息、输出可解释兴趣画像”的长期目标。

权威要求来自：

- Notion《B站兴趣画像｜项目 Idea》：公开数据可作为兴趣证据，但不同来源权重不同，结论应有证据且不得制造虚假的精确感。
- Notion《详细制作流程｜稳定性与扩展性优先》：v0.1 选择 2–3 个稳定公开来源；至少两个来源能稳定获取并标准化是进入 Phase 1 的必要条件。
- Notion《工程流程优化｜从 Issue 到 Release》：架构级工作必须经过书面 Spec 与用户审批，才可进入计划阶段。
- 已接受的 ADR-007：Source Qualification 与 Phase 0 Global Risk Gate 分开判断；来源 PASS 不代表 Phase 0 或后续工程已获准。

本 Spec 只描述来源组合和证据边界；不覆盖采集实现、Contract、评分、权限、存储、UI 或测试方案。

## 2. 当前事实与问题

截至 2026-09-28，本地 Phase 0 记录为 Source Qualification **PASS 2 / FAIL 1 / NOT_VALIDATED 1**：公开基础资料与公开动态在已证明的限定范围内 PASS；公开投稿因内容归属不足为 FAIL；公开收藏保持 NOT_VALIDATED。

基础资料的资格证据只证明身份/上下文信息可稳定读取，不能把它包装为第二类兴趣行为证据。公开动态是当前唯一已验证可承载兴趣相关正文的来源。若现在把投稿或收藏纳入，会超出已有证据并误称为可用来源。

## 3. 决定：v0.1 来源组合

### 3.1 公开动态：唯一兴趣行为证据源

v0.1 的兴趣推断只可使用当前已验证范围内、正常公开动态页面上可见的动态内容。该范围以现有 Phase 0 证据为准：正常已登录公开动态页、当前渲染卡片、已知正文结构，以及对引用、通用文案、合作占位和不可确认内容的拒绝或降级。

动态归属的现有证据仅为目标空间路由、非空页面头部身份和卡片可见作者显示名的一致；卡片没有可验证的作者 UID，因此这不是强身份保证。动态内容只能在该页面上下文中、且内容可确认时形成兴趣相关的行为证据。路由、头部身份或卡片作者显示名任一缺失或不一致时，该卡不产生兴趣证据；只记录当次来源状态为 unknown 或 unavailable，具体正式状态定义留待 Contract。内容归属不明、结构未知、必要字段缺失或页面状态不可信时，同样不得产生兴趣证据；不得补造内容、时间、链接或兴趣结论。

### 3.2 公开基础资料：身份与上下文，不参与兴趣推断

公开基础资料只用于确认分析对象和提供必要上下文，例如路由、UID、可见头部身份及公开自述的上下文信息。它不产生兴趣信号、不增加兴趣分数、不提高兴趣置信度，也不构成多源佐证。

### 3.3 明确排除的来源

| 来源 | v0.1 状态 | 原因 |
| --- | --- | --- |
| 公开投稿/作品 | 排除 | 当前为 FAIL；逐卡上传者与合作角色归属尚未充分确认。 |
| 公开收藏 | 排除 | 当前为 NOT_VALIDATED；重复稳定性与必要字段标准化证据不足。 |

排除并不代表这些来源永久不可用。未来若要纳入，必须作为新的范围变更：先取得用户对该来源 Spike question 与 probe 的批准，再完成相应 Source Qualification，最后申请并获得本 Spec 范围变更批准。

## 4. 产品表述与局限

v0.1 必须明确：兴趣结论当前来自**单一行为来源（公开动态）**，只能反映该来源在可见、可确认样本中的信号。

因此 v0.1 不得：

- 宣称“多源印证”“跨来源一致性”或等效结论；
- 用基础资料把单一行为来源包装成多源兴趣证据；
- 将投稿或收藏的未验证、失败或不可确认内容计入兴趣；
- 将 unknown、页面空壳、工具异常或访问限制当作空数据或正常数据。

该局限应作为产品结果和后续设计的约束，而非被评分规则静默掩盖。

## 5. 与 Phase 0 Gate 的关系

本决定仅冻结“2–3 stable public Sources”条目中的 v0.1 组合、用途与兴趣证据价值。它不更改其他 Gate 判定。

Phase 0 Global Risk Gate 仍为 **BLOCKED**。pagination 仍为 NOT_VALIDATED，同文档 SPA UID switch 仍为 PARTIAL；它们需要在各自获得批准的范围内处理。logged-out 已在其限定最低证据路径内 DONE，但不改变本 Global Gate。本 Spec 不授权新 Spike，也不把未完成项目降级、删除或解释为通过。

即使本 Spec 获批准，仍须完成已授权的 Phase 0 closure audit，并取得用户对当时 Global Gate 处置及进入 Phase 1 的明确授权，才可初始化工程骨架或实施任何产品能力。

### 5.1 修订（2026-09-29，已获用户批准）：延期验证的产品边界

`pagination = NOT_VALIDATED` 与 `SPA UID switch = PARTIAL` 仅可被记录为 deferred validation / residual risk；这不等于验证通过，也不改变 Global Gate、Phase 1 前置条件或本 Spec 的单一兴趣行为来源边界。历史实验和 fixture 保持原样。

| 项目 | 残余风险与禁止表述 | 重验条件 |
| --- | --- | --- |
| pagination | 不得称动态新批次、跨批去重、完整历史或长列表边界已验证。短列表的明确终止提示只限对应样本。 | 现行 v0.1 仍限已批准的当前渲染卡片；有合格长列表时，在既批范围内验证真实新批次与跨批重复。任何新增分页/完整历史能力验收或发布前仍缺证时，该新增能力只能明确标为未验证。 |
| SPA UID switch | 不得称同 document 跨 UID、旧内容隔离、旧请求取消或分析对象一致性已验证；新标签观察不替代同文档证据。 | 有身份明确的正常同 document 路径时，在既批范围内重验。任何 v0.1 同文档切 UID 能力验收或发布前，真实路径证据与受控切换/旧结果隔离测试须同时具备；任一缺失，该能力不得验收或宣称已验证。真实路径缺失时网页实测保持未验证；仅缺受控测试时，网页实测与能力验收须分开记录。 |

所有超出既批 Question + Probe 的样本类别、数量、尝试次数或实质性 Probe 变更，仍须重新审批。此修订已授权准备 closure audit，但不授权 Global Gate 改判、Phase 1、实现或新 Spike。

## 6. 非目标

本 Spec 不：

- 启动或设计新的浏览器 Spike；
- 自行修改 Global Gate 状态或将延期解释为验证通过；
- 定义正式 SourceAdapter、EvidenceItem、兴趣评分、权限或网络请求；
- 引入服务器、账号、API Key、私有接口、凭据读取或任何绕过限制的方式；
- 授权进入 Phase 1、执行实施计划或实现代码。

## 7. 本 Spec 的验收条件

本 Spec 获用户书面批准时，确认以下陈述全部成立：

1. 公开动态是 v0.1 唯一兴趣行为证据源，且仅限已验证范围。
2. 公开基础资料仅用于身份与上下文，不参与兴趣推断或置信度提升。
3. 投稿和收藏均不进入 v0.1：前者保持当前 FAIL，后者保持 NOT_VALIDATED。
4. v0.1 对外和对内均不得宣称多源兴趣印证。
5. 本 Spec 不改变 Phase 0 Global Gate，也不授权进入 Phase 1 或执行任何计划、Spike 或实现；延期验证只能作为 closure audit 的明确风险输入。

## 8. 审批后的下一关

来源组合 Spec 与延期验证修订均已获用户批准，Implementation Plan 也已获用户批准。该批准不进入 Phase 1，也不授权执行计划、实现代码、修改 Gate 或启动 Spike。只有已授权的 Phase 0 closure audit 完成、用户明确批准当时的 Gate 处置与进入 Phase 1，且再次确认本计划执行授权后，才可开始实施。
