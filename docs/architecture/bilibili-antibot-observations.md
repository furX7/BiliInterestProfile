# Phase 0：B站验证码与空态观察

历史实验：2026-09-27；修正版回归：2026-09-28（Asia/Shanghai）。
工具：普通 Codex 内置浏览器导航、公开 DOM 读取；用户自行正常登录。
禁止自动解验证、签名接口、身份切换、Cookie/Token 导出、主动采集接口及高频重试。

## 2026-09-28 回归观察

- 既有 A/B/C 动态各三次有效新页面读取，每读 12 卡；每账号明确 reload 一次。主页 video-section 各三次，每读 A 10/B 10/C 25 卡；各一次 reload。
- 动态离页再返回、主页跨账号后返回均替换页面；没有把同一 DOM 复读凑次数。没有观察 HTTP/业务码/缓存命中，不声称独立服务器请求矩阵已通过。
- 两项九次读取均未见可见 CAPTCHA、权限拒绝、请求失败或最终不明空态。这是当次观察，不证明这些状态不存在或未来稳定。
- A 的导航初始空壳随后正常显示内容，初始读不计有效次数也不判 empty。B 的投稿候选因合作归属过滤归零；不是来源无数据，结果 unavailable / attribution-unconfirmed。
- A reload、C 离页各有一次浏览器工具超时；不计有效实验，不归为 B站 request-failed。恢复后使用可确认完成的导航/reload，未重试受 CAPTCHA 阻塞的完整投稿子页。
- 主任务之后单次 B 收藏页显示“公开 视频数: 10”与资源，四夹摘要计数 10/13/15/15；没有真实 available-empty、permission-denied 或 request-failed 负例，收藏 Gate 仍 NOT_VALIDATED。
- 历史 CAPTCHA 与未登录未知空态证据继续有效，但本轮没有新的同类异常；无 403/412/429 实证。未解验证、切换身份、伪造请求、扫描内部 API 或扩大样本范围。

## 频率与可见性限制

- 本轮登录后测量窗口：UTC 14:39:12–14:54:39（北京时间 22:39–22:54）。
- A 读取时间差约 34 秒、86 秒；B 约 42 秒、94 秒；C 约 100 秒、82 秒。第一至第二次是同一渲染 DOM 复读，第三次包含刷新。
- DOM 读取没有主动发采集请求；正常导航/刷新会让网页自己加载。真实网络请求次数、并发、HTTP 状态与 API 业务码没有捕获。
- 未对受验证码阻塞的投稿子页自动重试。没有探索调用方式网格、换账号规避、伪造请求头或身份。
- 正常用户页面点击也可能触发限制；工具提供的点击与用户亲手操作不是同一实验，用户手动重复触发尚未测。
- 本轮未观察到显式 403/412/429；不是“没有限流”的证明。

## 保守策略建议（文档方案，未实现）

1. 用户主动访问目标页后，只读取已渲染公开内容，采样范围标为 visible-page/partial；不预取全账号，不滚动抓完整历史。
2. 发现验证码立即停止该来源；同一导航内保持受限状态，即使随后出现空态也不覆盖。
3. 缺少必要字段、身份不匹配或错误原因不明，返回 unavailable/unknown，保留原因，不返回成功 `[]`。
4. 若未来经批准增加网页响应观察，只观察该页本来发生的请求；审查数据范围及权限，不主动重放接口。
5. 只在用户正常刷新/切页后重新评估；不做风控后自动重试。明确区分网页加载、工具失败和来源失败。
6. 来源失败互不传染；完整度、来源状态与旧 UID 清理必须可见。不得把上述文档当成已验证 Adapter。
