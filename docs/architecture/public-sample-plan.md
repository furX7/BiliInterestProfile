## 来源候选

优先验证公开投稿与公开动态；若某类受验证/隐私限制，再审查公开收藏是否可作为候补。
暂不实现真实 Adapter，不把候选称为已冻结的“最稳定来源”。
只读取当前浏览器会话正常可见的公开信息；遇访问限制保留失败状态。

## 门槛证据

按本轮用户明确要求：每个来源至少三个适合的公开账号，每账号至少三次验证，
另有至少一个异常/不可访问案例；关键字段稳定映射，不把限制、请求失败或 schema 异常解释为空。
记录观察时间、浏览器、登录状态、刷新和映射版本，给出脱敏 Raw 与临时 Candidate 对照。
同页 DOM 复读与独立重新加载分别标明，不夸大网络稳定性；分页、隐私、真空和慢网未测时如实记录。
至少两个来源 PASS 才满足来源 Gate；即使满足，本轮也只报告并等待用户确认，不自动进入 Phase 1。
旧“两次复测”建议已由此次明确的三账号各三次要求替代。

## 样本隐私

- 不保存登录凭据、Cookie、Token、私信、私人收藏或浏览历史。
- 本轮允许 docs/fixtures/phase0/ 保存真实观察的脱敏摘要；不把真实正文替成虚构成功数据。
- UID/昵称/空间 URL 用别名；联系信息剔除；公开视频字段最小保留，不声称不可逆匿名化。
- 保留字段结构、异常形态和字符边界；真实派生与以后合成测试样本清楚区分。
- 合成 fixture 可验证 schema，但不能证明线上可访问性。
- 固定 expected 输出经人工审查；不随手更新 golden 来掩盖回归。
- 复现地址与 fixture 分开记录，避免匿名 fixture 留下真实账号链接。

本轮仅使用 docs/fixtures/phase0/ 临时 JSON；tests/fixtures、正式 Contract 和测试工程等待后续阶段。
